ما هو مجال البنية التحتية السحابية؟

الحوسبة السحابية تعني استخدام خوادم الإنترنت بدلاً من الأجهزة المحلية لتخزين البيانات وتشغيل التطبيقات ومعالجة المعلومات. أمازون AWS وGoogle Cloud وMicrosoft Azure هي العمالقة في هذا المجال، وكل شركة في العالم تقريباً تنتقل إلى السحابة الآن.

كل شركة تحتاجه

تقريباً 100% من الشركات الكبرى تعمل على السحابة أو تخطط للانتقال إليها، مما يعني طلب هائل على المتخصصين.

شهادات ذات قيمة

شهادات AWS وAzure من أعلى الشهادات قيمة في سوق العمل العالمي ومطلوبة بشدة.

رواتب مرتفعة جداً

متخصصو السحابة من أعلى المتخصصين رواتب في التقنية، خاصة مع خبرة في أمان السحابة.

لا يتطلب برمجة عميقة

يمكنك الدخول للمجال بمعرفة شبكات وأنظمة تشغيل وتعلم أدوات السحابة دون برمجة متقدمة.

خارطة طريق التعلم

أساسيات الشبكات والـ Linux

تعلّم أساسيات TCP/IP وأوامر Linux لأنها القاعدة التي تقوم عليها السحابة.

⏱ 4-6 أسابيع

منصة سحابية واحدة

ابدأ بـ AWS أو Azure وتعلّم خدماتها الأساسية مثل EC2 وS3 وVPC.

⏱ 8-10 أسابيع

Docker وKubernetes

تعلّم كيفية بناء وتشغيل التطبيقات داخل حاويات وإدارتها.

⏱ 6-8 أسابيع

Infrastructure as Code

تعلّم Terraform أو CloudFormation لأتمتة إنشاء البنية التحتية.

⏱ 4-6 أسابيع

الشهادات الاحترافية
